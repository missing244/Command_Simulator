BOX CHECK先算范围，再看三轴
# 1. 先算盒子三个方向的范围
盒子.x1 = min(x, x+dx)
盒子.x2 = max(x, x+dx) + 1

盒子.y1 = min(y, y+dy)
盒子.y2 = max(y, y+dy) + 1

盒子.z1 = min(z, z+dz)
盒子.z2 = max(z, z+dz) + 1

# 2. 碰撞箱三个方向都重叠，才选中
碰撞箱.x1 <= 盒子.x2  且
碰撞箱.x2 >= 盒子.x1  且
碰撞箱.y1 <= 盒子.y2  且
碰撞箱.y2 >= 盒子.y1  且
碰撞箱.z1 <= 盒子.z2  且
碰撞箱.z2 >= 盒子.z1

一句话：三个轴都重叠才算相交；任意一个轴不重叠，就不选中。

  • 缺省：只写 1 个或 2 个参数时，没写的默认为 0；但判定方盒边长仍然是 1，不是 0。
  • 负数：判定方盒向负方向延伸；+1 永远加在正方向侧，不是“朝负方向位置加”。
  • 不是看中心点：只要碰撞箱与方盒相交，仍然选中。
