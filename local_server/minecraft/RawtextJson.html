RAWTEXTJSON / 入门

一句话，
可以拆成很多段

基岩版的 rawtext 是一个列表。游戏从第一项读到最后一项，把每一项变成文字，再按顺序接起来。translate 则像一道填空题：先给模板，再用答案卡填进去。

rawtext: [ ... ] 按顺序显示 translate + with
rawtext
{ "rawtext": [ { "text": "Hello " }, { "translate": "%%s", "with": ["world"] } ] }
屏幕上
显示Hello world

01 / RawtextJson 语法

rawtext 后面，
先写一个方括号

rawtext 的值是一个列表，用 [ ] 包起来；列表里每一项用 { } 包起来，项与项之间用逗号隔开。读的顺序，就是显示的顺序。
标准格式：{"rawtext": [<组件1>, <组件2>]}

rawtext 的写法列表 · 循环
{
  "rawtext": [
    { "text": "Hello " },
    { "translate": "%%s", "with": ["world"] }
  ]
}
游戏按顺序读1 → 2
1 Hello 来自第一项 text
2 world 来自第二项 translate

02 / 文本组件

列表里的每一项，
可以是什么？

最常见的是文字、翻译、分数和实体名称。每一项只选一种内容；写什么，就会在对应位置显示什么。

text

纯文字

直接写要显示的字；\n 可以换行。空格也要自己写进去，游戏不会自动加。

{"text": "Hello\nWorld"}
显示：Hello ↵ World

translate

翻译 / 模板

先给一个语言键名或模板，再用 with 里的内容填空。语言键名会按当前语言显示译文。

{"translate": "commands.op.success",
 "with": ["Alex"]}
显示：已将 Alex 设为管理员

score

分数

读取记分板上的分数。多个分数会用逗号加空格连在一起。

{"score": {"name": "@s", "objective": "obj"}}
显示：42

selector

实体名称

显示被选中实体的名称；没有自定义名称时，显示实体类型名。

{"selector": "@a"}
显示：Alex, Steve

translate-with-rawtext

翻译 + 列表

with 里不一定是普通答案，还可以再放一个 rawtext 列表。游戏会先把这个小列表按顺序变成文字，再拿来填空。

{"translate": "%%s + %%s",
 "with": {"rawtext": [
   {"text": "X"},
   {"text": "Y"}
 ]}}
显示：X + Y

§ 格式化

颜色与样式

§4 深红，§6 金色，§l 粗体，§r 恢复默认。注意：§6 只改颜色，不会自动变粗。

{"text": "§4Red §6Gold §lBold"}
显示：Red Gold Bold
