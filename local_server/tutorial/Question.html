输入答疑

Q如何取消输入法的安全键盘模式？

用户通常需要在手机的系统设置内关闭输入法的安全键盘模式， 通常在设置中搜索安全输入即可搜索到安全输入的相关设置，关闭即可。

注意：如果用户在直播或录制视频中需要输入密码，关闭安全输入将极大威胁密码安全，因此用户需要权衡利弊。

Q为什么输入法的复制粘贴不起作用或粘贴内容差别大？如何解决？

因为选用的是 tkinter 作为 UI 模块创建的工具。tkinter 是桌面端 UI 模块，因此对电脑的适配较为完全， 而对移动端的适配就容易出现问题。

解决方法： 一些文字相关的操作，如果你需要执行复制、剪切、粘贴等操作，请使用软件提供的文本操作菜单执行相关文字操作。

UI 界面答疑

Q为什么我的 UI 显示的不完整？如何解决？

因为每个手机的设计不同，屏幕上的像素坐标也会大不相同， tkinter 在每个安卓设备上使用都会出现不一样的效果。

解决方法： 在 Pydroid 3 的主界面，点击左上角菜单，点击 Setting，点击 System， 下滑至末尾，点击 Tkinter: screen DPI，将 DPI 改为 320 或更小即可， 依照自己设备效果选择最合适的 DPI。
